# Basic Git Commands
---


`git` 
This command will let you know if git has installed on your machine or not


`git-v` OR `git--version` 
Displays git version installed on your machine

`git update-git-for-windows` 
Updates git version in windows operating system

`git config --global user.name "Girish"`
Set User name for Git

`git config --global user.email "girish.uppal@gmail.com"`
Set email address for Git

`git config user.name`
View Git User name

`git config user.email`
View Git email address
