# Repository
---

`git init`
Initialise git repository

`git status`
Check git repository status

`git add .`
Add all files into git repository

`git add hello.html`
Add specified file into git repository

`git commit hello.html`
Commit specified file into git repository

`git commit -m "git commit message"`
Commit all files into git repository

`git commit -a -m "git commit message"`
Commit git contents by bypassing staging

`git commit -m "git commit message" -amend`
Change message text of previous commit
